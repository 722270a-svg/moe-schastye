Мои данные

Все записи сохраняются локально в браузере на устройстве. Для переноса на другой телефон или компьютер используй экспорт и импорт.

Данные доступны локально, а при входе в облако синхронизируются между устройствами. Дополнительно сохраняй резервную копию.

📱 На iPhone

Открой опубликованную ссылку через Safari, нажми «Поделиться» → «На экран Домой». Приложение появится как отдельная иконка.

Для установки и работы без сети лучше разместить файлы на GitHub Pages. До публикации доступен просмотр файла в браузере.

☁️ Синхронизация

Один аккаунт на компьютере и iPhone. Хранение в закрытой таблице Supabase.

Войди, чтобы включить синхронизацию.

При регистрации может потребоваться подтверждение почты. Данные останутся на устройстве даже без сети; после входа они объединяются с облачными.
